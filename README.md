#  AI Model Hub

**A modern, sleek web platform that allows users to browse, subscribe to, and manage multiple AI models...**

## 🧠 Overview

AI Model Hub is a modern platform that allows users to explore and subscribe to multiple AI models in one place. It simplifies access to tools like ChatGPT, Claude, Gemini, and more with a clean and user-friendly interface.

##  Key Features

### 1. **Unified AI Model Marketplace**
- Browse many frontier AI models in a clean, responsive grid layout
- Each model card shows logo, pricing, short description, and popularity tags (`Popular`, `Favorite`, `Most Wanted`)

### 2. **Smart Cart System with Real-time Updates**
- Add multiple AI models to cart
- Smart duplicate prevention with "Item already in cart" toast
- Remove items easily
- Live cart counter and total calculation

### 3. **Seamless Subscription Flow**
- One-click "Subscribe Now"
- Visual feedback with "Subscribed ✓" state
- Free models handled gracefully
- Smooth checkout simulation with success notification
- Empty cart state with nice illustration

## 🚀 Run Locally

**Clone the project**
```bash
git clone https://github.com/toufiqweb/AI-Model-Hub.git
```

**Go to the project directory**
   
```bash
cd AI-Model-Hub
```

**Install dependencies**
   
```bash
npm install
```
**Start the development server**
   
```bash
npm run dev
```
**Open in browser**
   
```bash
http://localhost:5173
```
